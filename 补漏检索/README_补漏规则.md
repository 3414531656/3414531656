# 补漏检索 · 统一规则（任务 A–F 全部适用）

## 0. 身份与边界
- 每个任务一个独立检索单元；**禁止跨任务借数、借链接、借结论**。
- 只写本任务文件：`C:\Users\341453\Downloads\ln_marine_data\补漏检索\taskX.md`；下载物放 `补漏检索\X\`。
- 不改其他文件；不 spawn 子代理；不重复查已被上一轮否定的来源（见各任务说明）。
- 找不到就写「检索不到」+ ≥3 条检索式。**宁可空手，不要编造**（编造页码/ISBN/DOI/链接整份作废）。

## 1. 每条规定动作
每条结论五项齐全：**发布单位、文件全称、发布日期、页码/表号、可打开原始 URL**；另附 1–2 句**照抄原文**。
- 网页无页码：写「网页无页码；位于正文第 X 段/表 X」。
- PDF：必须自己下载后抽文本或逐页渲染核对，页码按 PDF 页序与页脚印刷页码双记。
- 缺任何一项，不进结论表。

## 2. 证据分级
- A＝政府/部委/监测机构原始文件可直接打开（PDF 已下载核对）；
- B＝原始文件存在但只看到检索摘要或转载全文；
- C＝论文、新闻、第三方转述（只作线索）。**论文必须给：期刊、年卷期、DOI、论文自述的数据来源**，不得冒充 A。

## 3. 本轮换源纪律
- 任务说明里列出的「已确认没有」的来源，**不要再花时间重复查**；只按给出的换源方向找。
- 无法获得数值时，仍要尽量把**载体信息**（书名、表名、出版信息、购买渠道、申请渠道）查清。
